About BloodConnect

A graph-based blood bank management system built for the DBMS project.

Neo4j + Flask
✚
OUR PROJECT

Connecting donors, blood banks and patients.

BloodConnect uses a graph database to represent the relationships between donors, donations, blood units, storage locations, patients, hospitals and blood requests.

Backend⌘
Python Flask
Routes and server-side logic
Database◎
Neo4j AuraDB
Graph nodes and relationships
Interface▣
HTML · CSS · JS
Responsive web dashboard
Data safety◇
Parameterized Cypher
Values passed as query parameters

Graph data model

The main relationships used by the application

Donor— MADE →Donation
Donation— PRODUCED →Blood Unit
Blood Unit— STORED_IN →Blood Bank
Patient— TREATED_AT →Hospital
Patient— MADE_REQUEST →Request
Request— FOR →Donation
